# Plataforma de Simulacros Saber Pro / Saber TyT — UNIPUTUMAYO

Aplicación web estática y gratuita (GitHub Pages) con simulacro de 50 preguntas (60 min),
resultados inmediatos y dashboard institucional conectado a Google Sheets.

## Actualizar el sitio
1. En tu repositorio: Add file → Upload files.
2. Arrastra los archivos/carpetas modificados (respeta rutas, ej. assets/js/preguntas.js).
3. Commit changes. GitHub Pages se actualiza en 1–2 min (recarga con Ctrl+F5).

## Archivos clave
- assets/js/preguntas.js → banco de preguntas + catálogos (programas y sedes)
- assets/js/config.js → URL de Google Sheets (ya configurada)
- google-apps-script/Codigo.gs → backend para pegar en Apps Script
- INSTRUCCIONES_GOOGLE_SHEETS.md → guía paso a paso
